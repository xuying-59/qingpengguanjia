# AI 使用过程记录

## 实现方式

问诊功能改为完全离线的 `LocalPlantAdvisor`。它根据作物名称、症状关键词、棚内温度/湿度/土壤湿度和照片颜色线索，匹配常见病害或虫害候选，输出处理步骤与药剂有效成分方向。

## 规则边界

1. 文字命中白粉病、灰霉病、霜霉或叶斑、蚜虫、叶螨、根腐等特征词时，优先给出对应候选。
2. 没有明确症状时，结合照片颜色特征和棚内环境进行低把握度初筛；高湿偏向霉病，干热偏向叶螨，低土壤湿度偏向萎蔫或根系问题。
3. 颜色分析只能提供初筛线索，不能替代病原检测、植保人员判断或产品标签。
4. 药剂推荐只给有效成分方向，不给出未经核实的剂量；使用前必须核对当地登记、标签、个人防护和采收安全间隔。

## 隐私与网络

问诊文字和照片只在设备本地处理，不需要配置网址、令牌或 OpenAI 密钥，也不会发送到外部系统。首页天气仍可按用户操作访问 Open-Meteo，和问诊功能相互独立。
